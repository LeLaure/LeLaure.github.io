Privacy Policy

Version 1.0
Operator the individual owner of the TikTok account @le.lore

This tool has one user: the person who runs it. It collects no data from anyone else, has no visitors, and serves no public interface.

1 Who this covers

The tool is private software run by a single individual to publish videos to that individual's own TikTok account. It is not distributed, not offered as a service, and has no end users beyond its operator.

No data is collected from TikTok users, viewers, or any third party. There is no website, no sign-up form, no cookies, and no visitor tracking.

2 What is stored

  • An OAuth token for the operator's own TikTok account, used solely to upload videos to that account.
  • Posting options returned by TikTok for that same account — the permitted privacy levels and the maximum video duration.
  • Upload records — the identifier and status TikTok returns for each upload, so failures can be diagnosed.
  • Performance figures for the account's own posts, if and when the operator enables that feature, in order to inform future subject selection.

All of it concerns the operator's own account and nobody else's.

3 Where it is stored

Data is held on a private server on the operator's own premises. It is not exposed to the public internet, and access requires the operator's own credentials. Tokens are stored with restricted file permissions and are never written to logs or reports.

4 Third-party processing

Producing a video involves external services. In each case, only content the operator created is sent — never anything about a TikTok user.

  • Language and speech models generate the narration script and the voice-over from it.
  • A multimodal model reviews the finished video for quality before publication.
  • Public media libraries supply licensed images used in the video.

No TikTok data, and no personal data belonging to anyone, is transmitted to these services.

5 Sharing and selling

Nothing is shared with, sold to, or disclosed to any third party. There is no advertising, no profiling, and no data brokerage of any kind.

6 Retention and deletion

Data is kept only while the tool is in use. The operator can revoke the tool's access at any time from TikTok's own account settings, which immediately ends all uploads and invalidates the stored token. Local data can be deleted at any time by removing it from the server.

7 Changes

This policy may be updated as the tool changes. The effective date above always reflects the current version.

8 Contact

Questions about this policy can be sent to the contact address listed at the top of this page.
